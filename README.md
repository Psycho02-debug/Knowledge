# Запоминалка слов

Офлайн-приложение (PWA) для запоминания информации: тексты со скрытыми словами, флеш-карточки и мини-курсы. Работает на iPhone как обычное приложение с домашнего экрана, без интернета и без сервера.

---

## Что это такое

Одностраничное приложение на чистом JavaScript. Без фреймворков, без сборки, без зависимостей — вся логика, разметка и стили лежат в одном файле `index.html`, рядом только шрифты.

**Все данные хранятся только на вашем устройстве.** Приложение не делает ни одного обращения наружу: нет аналитики, нет отправки данных, шрифты лежат рядом с приложением и попадают в кэш service worker. Обратная сторона — нет автоматической синхронизации между устройствами (для переноса материалов есть кнопка «Скопировать материал», см. ниже).

## Возможности

**При запуске сразу открывается папка «Термины»** — список её материалов, без захода через главный экран. Папка ищется по названию: регистр, пробелы по краям и «ё/е» не важны, а если её убрали внутрь другой папки, откроется этот модуль. Если папки с таким названием нет, приложение открывается на главном экране, как раньше. «Назад» из неё ведёт в список папок. Название задаётся одной константой `STARTUP_FOLDER_NAME` в `index.html`.

### Тексты

Материал — это заголовок и описание. В описании можно скрывать слова и учить их разными способами.

| Режим | Что делает |
|---|---|
| **Выбор** | Отмечаете слова, которые нужно скрыть |
| **Практика** | Скрытые слова открываются по одному. Как именно они выглядят до раскрытия, выбирается клавишами 2–4 или на экране материала: полностью скрытые, только первая буква или ваши вопросы |
| **Строка по кругу** | Для первых прогонов нового текста: на экране одна строка, её скрытые слова открываются по кругу снова и снова. Подробно — ниже, «Режим «Строка по кругу»» |
| **Вписать** | Нужно напечатать скрытые слова: по одному, несколько через пробел или весь текст сразу |
| **Собери текст** (на панели — «Игра») | Собрать текст из перемешанных слов. На экране материала два варианта. **«Собери текст по словам»** — перемешан весь текст сразу. **«Собери текст по строкам»** — перемешаны слова одной строки, а строки идут по порядку: сверху номер строки («1.», «2)», «а)» — как в тексте, а без номера — порядковый), под ним собираемая строка. Строки — те же, что в «Номерах»; знаки препинания держатся за словом, так что запятая не становится отдельной плиткой. Собрали строку — она остаётся на экране целиком, а на месте плиток появляется **«Следующая строка ›»** (на компьютере — `Return`). После последней строки — «Отлично!» и общее число ошибок. Кнопка «Игра» на панели и переход к соседнему материалу оставляют выбранный вариант. На компьютере в строке, где собирается текст, стоит поле для номеров, курсор в нём сразу. У первых десяти слов строки (по порядку текста; на экране плитки всё равно перемешаны) в углу плитки стоят цифры `1`–`9` и `0`: набранная цифра сразу ставит слово на место, `Backspace` убирает последнее слово, `Return` после собранной строки ведёт к следующей. Слова без номера — это всегда конец длинной строки, их в конце щёлкают мышью по порядку. Буквы, стрелки и цифры в поле никуда не переключают; цифры работают и когда курсор не в поле. На телефоне поля и цифр нет |
| **Тест** | Выбрать верное описание среди описаний других материалов той же папки |
| **Строки** | Карточка: с одной стороны первые буквы или слова каждой строки, с другой — полный текст |
| **Номера** | Видны только номера строк — «1.», «2.», «3.» (свой маркер строки или порядковый номер), текста нет вовсе. Кнопка **▶** у номера играет звук этой строки, если он добавлен (см. «Озвучка»). **«Показать строку»** открывает следующую строку целиком, **«Подсказка»** — следующее слово; всё строго по порядку, от первого слова к последнему. Когда открыт весь текст, главная кнопка становится «↺ Скрыть всё». Стрелки ‹ › по бокам — соседний материал, при переходе текст снова скрыт. На экране выбора режима — «Только номера строк» |
| **Вопросы** | Карточка: с одной стороны ваши вопросы к термину, с другой — сам термин |
| **Карточка** | Карточка: с лицевой стороны название термина, с оборотной — весь его текст целиком, без скрытых слов |
| **Пример** | Показывает пример использования |

Режимы переключаются панелью режимов, клавишами `1`–`7` или с экрана материала, а «Назад» возвращает на экран материала. Стрелки ← → открывают соседний материал в том же режиме — в том порядке, в каком материалы стояли в списке (с учётом поиска, сортировки и перемешивания). В «Строке по кругу» они листают строки, а соседний материал открывают за краем текста.

#### Режим «Строка по кругу»

Для первых прогонов нового текста, когда слова ещё не держатся в голове. На экране одна строка материала — крупно, без остального текста; под номером строки мелко — номер материала. На экране выбора режима — «Строка по кругу», клавиша `6` (работает и `7`).

- **Какие слова скрыты.** Те же, что во всех режимах: их выбирают кнопкой «Выделите слова для скрытия» под «Редактировать материал», другого способа скрыть слово нет. При входе они закрыты.
- **Круг.** Кнопки внизу — как в обычной практике. **«Открыть слово»** (на компьютере — пробел или `Return`) открывает закрытые слова строки по одному слева направо. Большая кнопка **«Открыть все слова»** (стрелка вверх) открывает строку целиком, а когда открыто всё, она становится **«↺ Ещё круг»** и прячет слова снова. Пробел и `Return` после последнего слова тоже начинают новый круг. Сверху счётчик: «Круг 2 · 1 из 3»; при входе идёт «Круг 1».
- **Фокус.** Кнопка **«Фокус на следующем слове»** (на компьютере — стрелка вниз) ведёт подсветку по словам строки, как в других режимах: с фокусом «Открыть слово» и пробел открывают все закрытые слова до слова под фокусом. Когда открыто всё, фокус гаснет — в новом круге его включают снова.
- **Нажатия.** Закрытое слово открывается и нажатием на него, открытое нажатием прячется обратно, долгое нажатие и `M` отмечают слово сложным.
- **Другая строка.** Стрелки ‹ › под большой кнопкой (на компьютере — ← →) переходят к другой строке в любой момент, а за краем текста — к соседнему материалу. Отдельной кнопки «Следующая строка ›» больше нет. Уходя со строки, её открытые слова снова прячутся: вернувшись, вы видите строку закрытой и проходите её заново — это следующий круг, счётчик растёт. Строку, где ничего не открыто, переход не трогает. У каждой строки свой счётчик, он сбрасывается при выходе из режима и при переходе к другому материалу. На строке без скрытых слов кнопки неактивны («Нет скрытых слов»), дальше ведут стрелки.
- **Выделить слова.** В углу карточки, рядом с «Подсказкой», — **«Выделить слова»** и **«Убрать выделение»**: они нужны, чтобы на время остановиться на трудных словах строки. «Выделить слова» (на компьютере — клавиша `Ж`, она же `;`) закрывает строку и включает выбор: нажатие по скрытому слову теперь не открывает его, а выделяет (пунктирная рамка внутри плашки), повторное — снимает выделение. Закончить выбор — той же кнопкой (на время выбора она «Готово») или клавишей `Ж`, большой кнопкой «Готово», пробелом или `Return`. После этого круг, счётчик («Круг 1 · 0 из 2»), фокус, подсказка и стрелка вверх работают только с выделенными словами, а остальные скрытые слова строки остаются закрытыми, бледнеют и на нажатие не отвечают. Новый набор слов начинает круги строки с первого.
- **Убрать выделение** (клавиша `Э`, она же `'`) снимает выделение строки: она снова закрыта целиком, круги с первого, и в работе все её скрытые слова. Выделение у каждой строки своё и не теряется при переходе между строками; уход со строки во время выбора заканчивает выбор. При выходе из режима и при переходе к другому материалу выделение сбрасывается. Разметку материала оно не меняет: какие слова скрыты, по-прежнему решает только «Выбор».
- **Раньше** рядом был режим «По строкам» — его убрали, остался этот. Одно время (v151–v154) слова здесь отмечались прямо на строке, своими отметками режима; это убрано: скрывают слова только в «Выборе».

#### Режим «Вписать»

Вписывать можно не только скрытые слова: обычные слова текста тоже принимаются, если стоят на своём месте — можно печатать хоть весь текст подряд. Обязательным остаётся только скрытое и ещё не вписанное слово; обычные и уже открытые разрешено пропускать. Счётчик «N / M» считает по-прежнему только скрытые.

Ошибка в середине длинной строки не обесценивает остальное: все верно набранные слова открываются, даже те, что идут после ошибки. Невписанным остаётся только несовпавшее слово — к нему сразу и возвращает подсказка «Сейчас слово N», а перейти к следующим скрытым словам можно, лишь ответив на него верно. Если несовпавших слов несколько, они перечислены в сообщении, а в поле остаётся первое из них.

Когда вписано последнее слово, вместо отдельного экрана поздравления открывается сам текст — целиком, со всеми вписанными словами. Следующий термин не подставляется сам: его открывают стрелкой «›» внизу или клавишей Enter (стрелка → работает так же). Тот Enter, которым вписано последнее слово, на следующий термин не уходит.

**Скрытое слово можно открыть нажатием** — пальцем или курсором, как в «Практике». Открытое так слово считается открытым: счётчик растёт, подсказка «Сейчас слово N» переходит к следующему, а вписать его всё равно можно — открытые слова при разборе ввода необязательны. Повторное нажатие прячет такое слово обратно. Вписанные слова от нажатия не прячутся: случайное касание не должно отменять набранное. Клавиатура на телефоне при нажатии на слово не закрывается. Если для слова висело сообщение об ошибке, открытие этого слова убирает и сообщение, и неверный набор в поле. Когда открыто всё, экран завершения честно пишет, сколько слов вписано и сколько открыто нажатием; «Отлично!» он говорит, только если всё вписано.

Текст и поле ввода в этом режиме — одна карточка, а не две: разделяет их полоса прогресса, она же показывает, сколько слов вписано.

Кнопка **«Фокус»** (на компьютере — стрелка вниз, она работает и когда курсор стоит в поле ввода) оставляет на экране одну строку — ту, где стоит слово, которое просят вписать. Карточка сразу становится короткой, и поле ввода оказывается прямо под строкой. Разметка внутри строки не меняется: те же плашки и та же подсветка текущего слова. Как только строка вписана целиком, фокус сам переходит на следующую. На материале из одной строки кнопка не показывается, а на экране с готовым текстом фокус не действует — там виден весь материал.

В режиме «Вписать» рядом с подсказкой стоит метка языка — **RU** или **EN**. Переключать раскладку клавиатуры со страницы браузер не даёт (это настройка системы, веб-API для неё нет), поэтому слово, набранное теми же клавишами в другой раскладке, просто засчитывается: при ожидаемом «состоит» подойдёт и «cjcnjbn». На телефоне, пока открыта клавиатура, карточка с текстом не уезжает за верхний край — её высота ограничивается, текст прокручивается внутри себя и сам подтягивается к текущему слову. Кнопка «Проверить» не забирает фокус у поля, так что клавиатура не закрывается после каждого слова.

#### Озвучка

Любой материал можно слушать вслух. Звук добавляете вы сами — двумя способами:
- **готовый аудиофайл** — например, озвучка, скачанная из бесплатного онлайн-сервиса;
- **свой голос** — запись с микрофона прямо в приложении.

Автоматической озвучки (голос телефона, нейроголоса) больше нет — её убрали в версии 138.

Звук добавляется **ко всему тексту сразу** — одним файлом или одной записью. Потом его можно разделить на блоки по пунктам. Пункты — те же строки, что в режиме «Номера», с теми же номерами; если строка одна, блок один на весь термин.

Всё про звук — в одном окне, **плеере озвучки**. Открывают его кнопка с динамиком в шапке любого режима изучения (справа, рядом с карандашом правки) и карточка **«🔊 Озвучка»** на экране выбора режима; число на карточке — сколько звуков добавлено к материалу. Отдельного окна «Озвучка» и кнопок **🔊** рядом с «Aa» и в режиме «Номера» больше нет — их убрали в версии 141.

Пока звука нет, плеер предлагает добавить его:
- **📁 Загрузить файл** — выбрать готовый аудиофайл: MP3, M4A, WAV и другие, до 50 МБ. На iPhone откроется приложение «Файлы» — скачанное из Safari лежит в папке «Загрузки». Если файл не получается воспроизвести (это не звук или формат не поддерживается), плеер сразу об этом скажет и ничего не сохранит.
- **● Записать голосом** — включает микрофон. В окне — крупный счётчик времени, кнопка **■ Стоп и сохранить** и весь текст по пунктам, чтобы читать его вслух. Делайте паузу между пунктами — тогда «🪄 По паузам» потом сама расставит границы блоков. После «Стоп» запись сохраняется сразу, а микрофон выключается.

Когда звук есть, заменить или удалить его — кнопка **Файлы и записи** в плеере. Там видно, что сейчас звучит (имя файла или «своя запись» и длительность), и кнопки **📁 Другой файл**, **● Записать голосом**, **🗑 Удалить звук**. Новый файл или запись заменяют прежний звук вместе с границами блоков.

**Звук к отдельным пунктам.** До версии 141 звук можно было добавить и к каждому пункту отдельно. Такие записи не пропадают: в режиме **«Номера»** у строки со звуком рядом с номером стоит **▶** — пункт можно послушать прямо во время вспоминания; а в плеере, пока звука ко всему тексту нет, есть **▶ Пункты по порядку**. Удалить их — **🗑 Удалить звук к пунктам** в плеере. Новых записей к отдельным пунктам не добавить.

**Где взять готовую озвучку.** Например, в бесплатном сервисе TextaVoice (textavoice.com): вставьте текст (до 2000 знаков за раз), выберите язык Russian и голос — Светлана (женский) или Дмитрий (мужской), нажмите Generate и скачайте MP3. Потом откройте плеер (кнопка с динамиком в шапке или карточка «Озвучка»), нажмите «📁 Загрузить файл» и выберите скачанный файл.

Мелочи, о которых стоит знать:
- Первый раз браузер спросит разрешение на микрофон. Если отказать, плеер подскажет, где его включить (на iPhone: Настройки → Safari → Микрофон). Нужна iOS 14.3 или новее.
- Запись сама останавливается через 5 минут. При закрытии плеера и при сворачивании приложения она останавливается и сохраняется: забытый микрофон не будет работать в фоне.
- Звук хранится на том устройстве, где его добавили. В перенос материалов текстом («Скопировать материал», «Скопировать папку») он не попадает. При удалении материала, модуля или папки их звук удаляется вместе с ними.

#### Плеер озвучки

Когда звук ко всему тексту есть, в плеере:
- **▶ / ❚❚** — играть и пауза; **−5** и **+5** — перемотка на 5 секунд; **⏮** — к началу текущего блока, повторное нажатие — к предыдущему; **⏭** — к следующему блоку.
- **Дорожка** — вся запись целиком, поделённая на пронумерованные блоки. Блок N — это пункт N текста: те же строки и номера, что в режиме «Номера». Нажатие на дорожку перематывает в это место, ведение по ней пальцем — тоже. Белая черта — где сейчас звук; текущий блок подсвечен, а над дорожкой — его номер («Блок 3 из 5») и текст.
- **Список блоков** под кнопками: нажатие на блок сразу играет его с начала, справа — время начала.
- **1× ⌄** — скорость. Нажатие открывает список: 0,5×, 0,6×, 0,75×, 0,9×, 1× (обычная), 1,1×, 1,25×, 1,5×, 1,75×, 2×; выбранная отмечена галочкой. Нажмите нужную — звук сразу пойдёт с ней, даже посреди игры. Список закрывается выбором, нажатием мимо него или `Escape`. Выбранная скорость запоминается и действует на любой звук в приложении.
- **Файлы и записи** — заменить звук другим файлом или своей записью, удалить его (подробно — в «Озвучке» выше).

Закрыть плеер — крестиком или `Escape`. Если звук играет, он играет и дальше: можно слушать и смотреть в текст. Кнопка в шапке при этом подсвечена, нажатие на неё возвращает в плеер. Звук на паузе при закрытии выключается, но плеер помнит место и продолжит с него — пока вы не откроете другой материал.

**Границы блоков.** Сначала они прикинуты по длине строк: речь идёт примерно с ровной скоростью, но ошибка в секунду-другую обычна. Поправить — кнопка **✎ Границы блоков**:
- **🪄 По паузам** — приложение само разбирает запись на речь и тишину и ставит границы в паузы между пунктами. На озвучке из сервиса это обычно сразу точно.
- **🎧 На слух** — звук играет с начала, а вы нажимаете большую кнопку «Начался блок N», как только слышите начало следующего пункта. Запаздывание пальца (0,3 с) учтено. «Отменить разметку» возвращает прежние границы.
- **Кружки на дорожке** — перетащите границу пальцем. После отпускания звук встаёт на начало блока, так что сразу слышно, верно ли.
- **−0,5 с**, **+0,5 с**, **Сюда** у каждого блока в списке: сдвинуть начало на полсекунды или поставить его туда, где сейчас стоит плеер. Удобно так: поставить паузу точно на первом слове блока и нажать «Сюда».
- **Сбросить** — вернуть прикидку по длине строк.

**✓ Готово** выключает правку. Границы сохраняются сразу, в самом материале. Новый файл ко всему тексту заменяет и границы: к другому звуку старые не подходят.

Если звука ко всему тексту нет, плеер предлагает загрузить файл или записать голос, а при звуке к отдельным пунктам — ещё и послушать их по порядку. У материала из одной строки плеер играет звук этой строки, и блок в нём один.

#### Режим «Карточка»

Этот режим ничего не требует настраивать: карточка собирается из самого материала, поэтому она есть у каждого материала сразу — и у всех уже созданных, и у каждого нового. Создавать, заполнять и обновлять её не нужно, при правке текста оборотная сторона меняется вместе с ним. Знаки препинания на оборотной стороне возвращаются к словам: текст хранится в виде «слово , знак», но читать его так неудобно, а чипов в этом режиме нет.

**Размер текста** карточки меняется кнопкой **«Aa»** над ней — ползунком от 50% до 200%. Размер запоминается **у каждой карточки свой**: короткий термин можно сделать крупным, а длинный текст на обороте — мельче, и при следующем открытии карточка покажется с тем же размером. Он хранится в самом материале и сохраняется вместе с ним, а 100% — размер по умолчанию. Одно значение действует на обе стороны карточки.

Кнопка **«Во весь экран»** убирает шапку, панель режимов и нижнюю навигацию — остаются карточка, «Перевернуть» и стрелки ‹ ›, а сверху «Aa», номер карточки и ✕. Так можно листать карточки подряд: режим держится при переходе к соседней и выключается при выходе из «Карточки». Длинный текст прокручивается, а кнопки сверху и снизу остаются на месте. Свернуть — ✕ или Escape. На компьютере и iPad вдобавок включается полноэкранный режим браузера; на iPhone браузер этого не умеет, но приложение с домашнего экрана и так открыто без панелей Safari, поэтому карточка занимает весь экран.

#### Правка текста и выбор слов

Исходный текст можно открыть на редактирование из **любого** режима — карандаш справа вверху. В окне редактирования есть кнопка **«Сохранить и выделить слова»**: она сохраняет правку и сразу открывает выбор слов, не возвращая на экран термина. В режиме «Выбор» та же правка доступна и кнопкой **«Редактировать текст»** под карточкой. Скрытые слова, звёздочки сложных и вопросы при этом переезжают на новые позиции сами, даже если текст сдвинулся.

Знаки препинания отделяются от слов пробелом с обеих сторон: «(текст),» становится «( текст ) ,». Иначе скобка и запятая уезжали бы под скрытие вместе со словом. Не трогаются маркеры списка («1.», «2)»), дробные числа, дефис внутри слова и минус перед числом, а также скобка, открытая внутри токена, — «f(x)» остаётся целым. Уже созданные материалы приводятся к этому виду при первом запуске новой версии — разметка скрытых слов, вопросы и отметки сложных при этом остаются на своих словах.

Разметка скрытых слов проверяется при каждом запуске и при каждом сохранении материала: если она когда-то съехала с реальных слов, она возвращается на место сама.

Кнопка **«Выделить все слова»** отмечает разом всё, что можно скрыть. Знаки препинания и номера пунктов не выделяются никогда: ни кнопкой, ни клавишей `/`, ни нажатием на сам знак — он рисуется приглушённым и не реагирует на нажатие. Знак, отмеченный в старом материале, снять по-прежнему можно.

В режиме «Выбор» есть два способа скрыть выделенные слова:

- **«Скрыть слова»** — просто прячет их;
- **«Скрыть через вопросы»** — прячет и просит написать свой вопрос к каждому слову.

Разница только в вопросах. Как бы вы ни скрыли слово, доступны **все** режимы изучения ниже — и «Полностью скрытые», и «Только первая буква». Вопрос нужен лишь режиму «Вопросы к выбранным словам»: без него там показывается пустая плашка.

**Порядковых номеров на скрытых словах нет** ни в одном режиме: скрытое слово — это просто цветной квадрат, зелёный или красный, если слово отмечено сложным. Надпись на плашке остаётся только там, где она подсказывает: первая буква в «П_», открытые подсказкой буквы и свой вопрос к слову в «?». Пустая плашка держит прежний размер — его задаёт невидимая цифра, поэтому квадрат растёт вместе с размером текста из «Aa». Плашки заметно ниже строки, и между рядами плашек всегда есть зазор: они не касаются друг друга и не раздвигают строки, а открытое слово той же высоты, что и закрытое. Пунктирная рамка выделенного слова в «Строке по кругу» нарисована внутри плашки.

### Как открываются скрытые слова

Скрытое слово открывается **нажатием на него** — в любом порядке. Повторное нажатие прячет его обратно.

**Кнопка «Открыть слово»** в нижней панели (рядом с «Фокус на следующем слове») и **клавиша Return** на компьютере открывают следующее скрытое слово строго по порядку текста. Считаются только скрытые слова: обычные слова между ними пропускаются, уже открытые (нажатием или подсказкой) — тоже. В режиме вопросов склеенная группа «вместе с предыдущим» открывается одним нажатием.

**С включённым фокусом** «Открыть слово» (и Return) открывает за одно нажатие **все** ещё закрытые скрытые слова от начала текста до слова под фокусом включительно — фокус показывает, докуда вы дочитали, и всё, что выше, вспоминать уже не нужно. Если под фокусом было скрытое слово, фокус после этого переходит дальше. Если до фокуса открывать уже нечего (всё выше открыто, а фокус стоит на обычных словах), открывается следующее скрытое слово после фокуса, и фокус перескакивает за него. Работает во всех трёх видах скрытия — квадраты, первая буква, вопросы; в «Выборе» и «Вписать» у Return своя роль. Когда открыто всё, кнопка гаснет (но остаётся на месте), а клавиша ничего не делает.

Главная кнопка внизу — **«Показать все скрытые слова»**: она открывает все слова разом, чтобы свериться с текстом целиком. Если был включён режим фокуса, он выключается — выделение со слова, где фокус остановился, пропадает, и текст читается ровно, без приглушённых слов. После этого кнопка становится «↺ Скрыть все слова» и прячет слова обратно; фокус при этом сам не возвращается. На компьютере то же самое делает стрелка вверх.

Экран открывается ровным: все скрытые слова выглядят одинаково, ни одно не выделено, соседние не приглушены. Раньше первое скрытое слово сразу подсвечивалось как «следующее» — эта подсветка убрана. Выделить слово теперь может только **режим фокуса** (см. ниже), а включает его только кнопка «Фокус на следующем слове» или стрелка вниз.

### Текст не скачет

Открытое слово длиннее квадратика и может перенести строку, но текст из-за этого не прыгает:

- **Положение текста закрепляется при входе в материал.** Текст встаёт в карточке так же, как раньше, — по центру, но прибавка от открытых слов растёт только вниз. Раньше центр пересчитывался на каждое открытие, и все строки, даже не менявшиеся, дёргались на полстроки.
- **Экран держит то, куда вы смотрите.** Когда меняется текст выше видимой части, страница незаметно докручивается на ту же величину ещё до того, как кадр попадёт на экран. С включённым фокусом на месте остаётся слово под фокусом (важно для «Открыть слово», которое открывает всё выше него). При «Показать все / Скрыть все» на месте остаётся середина экрана. При нажатии на слово — то, что вверху экрана. В Chrome так умеет сам браузер, а Safari на iPhone — нет, поэтому это сделано в приложении.
- **Нижняя панель не меняет высоту.** Кнопки «Фокус на следующем слове» и «Открыть слово» не исчезают, когда открыто всё, а гаснут. Раньше панель становилась ниже, страница укорачивалась, и экран подпрыгивал вверх.
- Прокрутка, когда нужна, — плавная и только вниз: если слово под фокусом или только что открытое ушло под нижнюю панель, экран мягко подтягивается к нему.

Замер на телефонном экране: первая строка короткого текста при открытии восьми слов раньше сдвигалась трижды примерно на 30 px, теперь — ни разу. Слово под фокусом после «Открыть слово» в середине длинного текста раньше уезжало на 270 px, теперь стоит на месте (2 px — это подъём выделенного чипа).

### Сложные слова

Слово, которое никак не запоминается, можно отметить: **долгое нажатие** по нему в режиме практики, повторное — снимает отметку. На компьютере то же самое делает правая кнопка мыши или клавиша `M` — она отмечает слово под фокусом, а если фокус выключен — первое ещё не открытое слово текста.

Отмеченный чип становится красным, а его содержимое белым — на экране с полусотней слов одну звёздочку в углу приходилось выискивать. Красный отличается от соседей прежде всего оттенком, а не яркостью: заливка взята в той же полосе светлоты, что у обычного чипа. Звёздочка при этом остаётся. Открытое слово подсвечивается тем же красным, только полупрозрачным — иначе сплошной блок среди строк читался бы тяжело.

Отметка держится и после того, как слово раскрыто, переживает смену режима изучения и сохраняется вместе с материалом. Красным такие слова показываются и в режиме **«Вписать»**: отметка относится к самому слову, а не к режиму, — если слово трудно вспоминается, знать об этом надо и когда его вписываешь. Слово, которое вписывают прямо сейчас, остаётся красным, но обводка у него светлее, чтобы «сейчас это» по-прежнему читалось.

**Выделение текста в карточке выключено целиком**, а не только на чипах. iOS соревновался за тот же жест: долгое нажатие поднимало лупу, красило чип синим и предлагало «Скопировать», а отметка часто не доходила. Запрета на одних чипах не хватило — выделение начиналось на обычном слове или на пробеле между ними и протягивалось поверх чипов, поэтому гасится весь контейнер. Копировать оттуда нечего: на месте скрытого слова — пустой квадрат или первая буква, а не текст. Материал целиком копируется кнопкой **«Скопировать материал»**.

### Подсказка

Если слово не вспоминается, кнопка **«💡 Подсказка»** в правом верхнем углу карточки с текстом открывает его по буквам с начала. Каждое нажатие добавляет одну букву: «С_», «Са_», «Сам_» и так далее. Последняя буква всегда остаётся скрытой — раскрыть слово целиком можно нажатием на него, подсказка это не подменяет. После первого нажатия кнопка называется «Ещё букву».

Работает одинаково во всех трёх режимах скрытия. В режиме «только первая буква» первое нажатие открывает вторую букву — первая и так видна.

Подсказка относится к слову под фокусом, а если фокус выключен — к первому ещё не открытому слову текста: слова обычно открывают сверху вниз, и застревают как раз на нём. Буквы появляются прямо на этом слове, так что видно, к какому слову она относится. Когда подсказывать больше нечего, кнопка гаснет, но остаётся на месте.

### Режим фокуса

**Режим фокуса** подсвечивает одно слово, приглушая остальные скрытые. При открытии экрана он всегда выключен — включается только кнопкой **«Фокус на следующем слове»** над главной кнопкой (на компьютере — стрелкой вниз) и встаёт на первое слово текста.

Фокус идёт по **всем** словам текста по порядку — скрытым, обычным и уже открытым, включая предлоги и союзы, — как палец, ведущий по строке. Пропускаются только знаки препинания, номера пунктов в начале строки («1.», «2)») и разделители «/»: это не слова. Скрытое слово фокус не пропускает никогда — в том числе скрытые числа вроде «24», «4090» или «9»; число внутри фразы — обычное слово, номером пункта оно не считается. После последнего слова фокус возвращается к первому.

«Фокус на следующем слове» переносит подсветку на один шаг вперёд, ничего не раскрывая. Скрытые слова проходятся по одному — их и надо вспоминать поодиночке. А вот **обычные слова между ними подсвечиваются связкой**, все подряд до следующего скрытого: перечитывать «ускоряет поиск по таблице за счёт» по одному слову незачем, связка читается одним взглядом. На тексте из тринадцати слов выходит десять шагов вместо тринадцати.

Скрытое слово под фокусом открывается нажатием на него — и фокус сразу переходит дальше. «Подсказка» и отметка сложного (`M`) относятся к слову под фокусом; на связке обычных слов они молчат.

Фокус сбрасывается сам при переходе к другому материалу, смене режима скрытия и нажатии «Показать все скрытые слова». **Когда все скрытые слова открыты, фокуса нет** — каким бы способом их ни открыли: нажатием, `Return` или «Открыть слово». Вспоминать больше нечего, поэтому подсветка гаснет, кнопка «Фокус на следующем слове» становится неактивной, а стрелка вниз ничего не делает. В «Строке по кругу» то же касается строки: открыли её целиком или перешли на строку без закрытых слов — фокус выключается. Включить его снова можно там, где есть закрытые слова: на другой строке или в новом круге. Подсказка по буквам слово целиком не открывает (последняя буква остаётся скрытой), так что фокус на нём остаётся. На компьютере им можно управлять с клавиатуры: стрелка вниз — включить и вести дальше, Delete — выключить.

### Размер текста

**Размер текста** в практике настраивается кнопкой «Aa» — от 50% до 150%. Настройка запоминается. У «Карточки» размер свой у каждого материала (см. «Режим «Карточка»»).


### Папки и список материалов

Материалы лежат в папках, а внутри папки можно завести **модули** — вложенные папки на один уровень. Открытая папка показывает и свои материалы, и материалы всех модулей; модуль — только свои.

- **Поиск** по названию, **сортировка** (сначала первые или последние, клавиша `W`) и **перемешивание** (`S`).
- **«Только сложные»** оставляет материалы, помеченные сложными, а **«Сбросить сложные»** снимает все пометки.
- На телефоне карточку материала можно **смахнуть**: вправо — пометить сложной или снять пометку, влево — снять пометку.
- **Порядок** материалов меняется перетаскиванием за ручку на карточке — в пределах одной папки или одного модуля.
- **«В модуль»** переносит отмеченные материалы из папки в один из её модулей.
- **Игры по всей папке**: «Тест» (от двух материалов) и «Сопоставление» названий с описаниями (от четырёх). Играть можно на всех материалах или на выбранных.
- **«Загрузить список»** добавляет сразу много материалов — простыми парами «название, описание» или в формате переноса (см. ниже).
- Кнопка экспорта на карточке папки в списке папок сохраняет её JSON-файлом со всеми полями. Обратного импорта из файла нет — для переноса служат кнопки копирования ниже.

### Флеш-карточки

Двусторонние карточки «вопрос — ответ», собранные в папки.

| Режим | Что делает |
|---|---|
| **Карточки** | Классическое перелистывание с переворотом. На карточке только её текст, без подписей «Лицевая сторона» и «Нажмите…». Перевернуть — тап по самой карточке; под ней, с запасом по отступу, чтобы не задеть карточку пальцем, — «Назад» и «Дальше» (на последней — «Завершить»), над ней «☆ Сложная» и «✎ Изменить» — правка карточки прямо по ходу изучения. В шапке под подзаголовком — **«↺ Начать заново»** (или клавиша `R`): после подтверждения возвращает к первой карточке того же прохода; на первой карточке кнопка неактивна |
| **Заучивание** | Адаптивно: выбор ответа → верно/неверно → вписать. Слабые карточки повторяются |
| **Письмо** | Только ввод ответа с клавиатуры |
| **Тест** | Смешанный экзамен, все типы вопросов подряд |
| **Подбор** | Соединить термины с определениями на скорость |
| **Просмотр** | Весь набор списком, отметка сложных карточек |

Опционально включается таймер на ответ (5–300 секунд).

**Сложные карточки.** В режиме «Карточки» текущую карточку можно отметить сложной — кнопкой **«☆ Сложная»** рядом с номером карточки или клавишей `S`; повторное нажатие снимает отметку. Это та же отметка, что звёздочка в «Просмотре», и сохраняется вместе с карточкой. Кнопка **«Только сложные (N)»** на экране папки запускает изучение одних отмеченных карточек — в подзаголовке тогда написано «Только сложные карточки», а «Пройти снова» и «Перемешать» на экране завершения сохраняют этот выбор. Отметка, снятая или поставленная по ходу занятия, состав текущего прохода не меняет — он обновится при следующем запуске. Пока сложных нет, кнопка неактивна; если отметки сняли все, «Пройти снова» вернёт к папке.

**Номер значения (2) (3) (4).** В окне новой карточки и в окне правки в правом нижнем углу обоих полей — лицевой и оборотной стороны — стоят кнопки **(2)**, **(3)**, **(4)**. Нажатие дописывает номер в конец стороны: «Угроза» → «Угроза (2)»; другой номер заменяет уже стоящий, повторное нажатие того же — убирает. Кнопка выбранного номера подсвечена. Клавиатура на телефоне при нажатии не закрывается. Между полями, на их стыке, — круглая кнопка-иконка **⇅** (без текста): меняет местами текст лицевой и оборотной стороны этой карточки (сохраняется кнопкой «Сохранить»). Эти кнопки есть только у флеш-карточек — в окне материалов их нет.

**Продолжение с места остановки.** «Изучать» (и клавиша `1`) начинает с той карточки, на которой вы вышли в прошлый раз, — даже после перезапуска приложения. Когда колода пройдена до конца («Завершить»), следующий раз начнётся с первой карточки. «Перемешать» и «Только сложные» всегда идут с начала и место не сбивают.

**Поиск по карточкам** — поле над списком «Карточки в папке». Ищет по лицевой и оборотной сторонам, без учёта регистра, «ё» и «е» считаются одной буквой. В режиме выбора «Выбрать все» отмечает только найденные.

**Порядок списка «Карточки в папке»** — как у материалов: кнопка-стрелка справа от заголовка или клавиша `W` ставит последние добавленные карточки сверху; повторное нажатие возвращает обычный порядок (сначала первые). В том же порядке, что в списке, идут карточки при **«Изучать»** и клавише `1`, а также в «Только сложные», «Просмотре» и «Письме». «Перемешать» и «Заучивание» по-прежнему перемешивают. Сами карточки не меняются, а после перезапуска приложения порядок снова «сначала первые».

**Какая сторона главная — решаете вы.** На экране папки под кнопками «Изучать» стоит панель «Сначала показывается» с примером первой карточки («Угроза → Threat») и кнопкой **«⇅ Поменять»**; то же делает клавиша `E` (`У`) — меняет местами лицевую и оборотную стороны **всех** карточек папки; на пару секунд под кнопками появляется подтверждение. Повторное нажатие возвращает как было. Меняются сами карточки, поэтому новый порядок сторон действует во всех режимах и сохраняется при переносе папки; отметки «сложная» и картинки остаются при своих карточках.

**Перенос карточек на другое устройство** — так же, как у текстов. На экране папки над списком «Карточки в папке» две кнопки:

- **«Скопировать папку»** — кладёт в буфер всю папку: название и все карточки. На другом устройстве нажмите «+» в разделе «Карточки» и вставьте текст **в поле названия** новой папки: название подставится само, а под полем появится «Будет вставлено карточек: N». После «Сохранить» папка создаётся сразу со всеми карточками.
- **«Выбрать карточки»** включает режим выбора: нажатие по карточке отмечает её галочкой, есть «Выбрать все» и «Отмена». **«Скопировать выбранные (N)»** кладёт в буфер только их. На другом устройстве откройте нужную папку → **«Загрузить список карточек»** и вставьте — карточки добавятся к уже лежащим. Туда же можно вставить и целую папку.

Переносится всё без потерь: многострочные стороны (и пустые строки внутри них), отметка «сложная», картинка. Текст можно переслать себе чем угодно — в Telegram, заметками; карточки с картинками делают его заметно длиннее. Формат читается глазами и при желании правится руками:

```
Папка карточек: Английский

Лицевая: Evidence
Оборотная: доказательство
Сложная: да

Лицевая: race condition
Оборотная:
состояние гонки —
результат зависит от того, кто успел первым
```

Строка «Папка карточек:» есть только при копировании папки целиком. Многострочная сторона пишется строками под словом «Лицевая:» или «Оборотная:». Если строка внутри карточки сама начинается с одного из этих слов, при копировании перед ней ставится обратная косая черта `\` — так она не начнёт новую карточку, а при вставке черта убирается. Простой формат из шаблона для нейросети («строка — пустая строка») по-прежнему работает.

В «Заучивании» вопрос усложняется по мере успехов: сначала выбор из вариантов, потом «верно / неверно», затем ответ с клавиатуры. Ошибка возвращает карточку на шаг назад и ставит её в очередь снова. Успехи считаются только в пределах занятия; между занятиями сохраняется лишь пометка «сложная».

При первом запуске появляются готовые наборы **«NASA · Планеты»** и **«Britannica · Нейроны»**. Каждый предлагается **один раз**: удалённый или переименованный набор больше не возвращается. Раньше они подкладывались при каждом запуске, если папки с таким названием не было, и удалить их насовсем было нельзя. Названия уже предложенных наборов хранятся отдельным ключом `wordMemorizerBuiltInSets`. Набор, который появится в будущей версии, придёт как новый — тоже один раз.

**Загрузка списка карточек.** Кнопка **«Загрузить список карточек»** на экране папки добавляет сразу весь набор. Формат один и тот же для вставки текстом и для файла:

```
ubiquitous
вездесущий, повсеместный

Идемпотентность
Свойство операции давать тот же результат при повторном применении.
Повторный запрос ничего не меняет.

race condition
состояние гонки — результат зависит от того, кто успел первым
```

Первая строка блока — лицевая сторона, следующие — оборотная (её можно растянуть на несколько строк), между карточками пустая строка. Русский и английский можно вперемешку, порядок сохраняется. Если пустых строк нет вовсе, строки читаются парами.

В окне есть готовый **шаблон** с этими правилами и кнопкой «Скопировать шаблон» — его можно отдать нейросети, чтобы она прислала материал сразу в нужном виде.

Файлы читаются четырёх видов: **.xlsx** (лицевая сторона в столбце A, оборотная в B), **.docx** (таблица из двух столбцов или те же пары абзацев), **.csv** и обычный текст. Строка-заголовок вроде «Лицевая сторона / Оборотная сторона» отбрасывается сама. Таблица после чтения показывается в поле уже в виде блоков — видно ровно то, что будет создано, и это ещё можно поправить руками. Строки, оставшиеся без пары, не пропадают молча: окно говорит, сколько их и какая первая.

Разбор .xlsx и .docx сделан без единой внешней библиотеки: оба формата — это ZIP с XML внутри, распаковку делает штатный `DecompressionStream`, разбор — штатный `DOMParser`. Приложение остаётся одним файлом без зависимостей и без обращений в сеть. Старые .xls и .doc не читаются — их нужно пересохранить.

### Курсы

Мини-курсы с дорожной картой уроков. Урок состоит из необязательной теории и заданий двух типов: тест (один или несколько правильных ответов) и сопоставление пар. Уроки открываются по порядку — следующий доступен после прохождения предыдущего.

### Перенос материалов между устройствами

В режиме «Выбор» есть кнопка **«Скопировать материал»**. Она копирует название и описание вместе с разметкой скрытых слов в таком виде:

```
Название: CSAT
Описание:
1. {{Структурированное}} сообщение по {{единому::какой?}} шаблону
```

Этот текст можно переслать себе любым способом (например, в Telegram) и вставить в поле «Название материала» **или** «Описание материала» на другом устройстве — приложение само разложит всё по нужным полям и восстановит скрытые слова с подсказками.

### Порядок папок

Папки можно расставить в своём порядке: стрелки в правом нижнем углу карточки поднимают и опускают её на одну позицию. На краях списка стрелка гаснет. Порядок сохраняется вместе с данными.

### Перенос выбранных материалов

Кнопка **«Выбрать материалы»** на экране папки включает режим выбора: карточки получают галочки, клик отмечает материал вместо открытия. Дальше **«Скопировать выбранные»** кладёт в буфер только их — с названиями и разметкой скрытых слов.

На другом устройстве этот текст вставляется в **«Загрузить список»**, и материалы добавляются в текущую папку, ничего не затирая. То же окно по-прежнему принимает и простой список без разметки — формат определяется сам.

Выбор держится за позицией материала в папке, а не за номером карточки на экране, поэтому поиск и сортировка его не сбивают.

### Перенос целой папки

Кнопка **«Скопировать папку»** на экране папки копирует её целиком — с названием, всеми материалами, модулями и разметкой скрытых слов:

```
Папка: Нейросети

Название: GPU
Описание:
{{Скорость}} математических вычислений

Модуль: Основы

Название: Токен
Описание:
{{Минимальная}} единица текста
```

Чтобы вставить, откройте создание новой папки и вставьте текст **в поле названия** — приложение разберёт его целиком и покажет, сколько материалов и модулей будет создано. Работает в любую сторону: с компьютера на телефон, обратно и между устройствами одного типа.

Разделитель между материалами не нужен: строка «Название:» сама начинает новый материал, а «Модуль:» — вложенную папку.

**Если по дороге поехали переносы строк.** Мессенджеры и заметки иногда превращают часть переносов в пробелы, и текст приходит так: `Название: АПИ Описание: 1 - {{Часть}} {{программного}} {{кода}}` — заголовки на одной строке, без пустых строк между материалами. Приложение понимает и такой вид: «Описание:» может стоять на строке названия, и текст описания может начинаться сразу после двоеточия. Переносы строк Windows и iPhone (`\r\n`, `\r`, служебный символ U+2028) тоже приводятся к обычным. Раньше из такого текста получались материалы с названием вроде «АПИ Описание: …» и пустым текстом.

## Управление с клавиатуры

На компьютере большинство действий доступно без мыши. Клавиши работают и в русской раскладке.

| Клавиша | Где работает | Действие |
|---|---|---|
| `1` `2` `3` `4` `5` `6` | внутри материала | Режимы: выбор слов, полное скрытие, первая буква, вопросы, вписать, «Строка по кругу». «Строку по кругу» открывает и `7`. В «Собери текст по строкам» цифры выбирают плитки, а не режимы |
| `]` или `` ` `` | везде | Создать: на списке материалов — материал, на списке папок — папку, на главной — материал или карточку. Внутри материала — открыть его на редактирование |
| `E` (`У`) | внутри материала | Открыть материал на редактирование |
| `Shift` | практика | Подсказка: открыть ещё одну букву слова под фокусом, а без фокуса — первого неоткрытого |
| `↑` | практика | Показать или скрыть все слова разом — то же, что главная кнопка. В «Строке по кругу» — «Открыть все слова»: открыть скрытые слова строки, а если они открыты — спрятать их снова (новый круг) |
| `Пробел` или `Return` | «Строка по кругу» | «Открыть слово»: следующее скрытое слово по порядку (с фокусом — все до слова под фокусом), после последнего — спрятать их снова, новый круг |
| `Ж` (`;`) | «Строка по кругу» | «Выделить слова»: начать выбор слов строки, повторно — «Готово», закончить выбор |
| `Э` (`'`) | «Строка по кругу» | «Убрать выделение»: снова работать со всеми скрытыми словами строки, круги с первого |
| `Return` | «Собери текст по строкам» | Следующая строка, когда текущая собрана |
| `1`–`9`, `0` | «Собери текст по строкам» | Поставить слово с этим номером (номера стоят в углу плиток первых десяти слов строки). Режимы и «Карточки» здесь цифрами не переключаются |
| `Backspace` | «Собери текст по строкам», поле номеров | Убрать последнее собранное слово |
| `Return` | практика | Открыть следующее скрытое слово по порядку текста; обычные и уже открытые слова пропускаются. С фокусом — все скрытые слова до слова под фокусом включительно. |
| `R` (`К`) | практика | Скрыть снова все открытые слова. В «Строке по кругу» — спрятать слова строки и начать новый круг |
| `↓` | практика | Включить фокус и вести его по словам |
| `Delete` | практика | Выключить режим фокуса |
| `←` `→` | внутри материала | Предыдущий и следующий материал. В «Строке по кругу» — предыдущая и следующая строка (открытые слова строки, с которой ушли, снова прячутся), за краем текста — соседний материал. В режиме «Вписать» работают и когда курсор стоит в поле ввода; каретку внутри поля двигают те же стрелки с Shift, Alt или Cmd |
| `↓` | режим «Вписать» | Фокус на строке: на экране остаётся только текущая строка. Работает и из поля ввода |
| `Enter` | режим «Вписать», всё вписано | Следующий материал |
| `↑` `↓` `Enter` | тест | Выбрать вариант ответа и подтвердить |
| `S` | практика | Пометить материал сложным или снять пометку |
| `M` (`М`) | практика | Отметить сложным слово под фокусом (без фокуса — первое неоткрытое) или снять отметку |
| `/` | выбор слов | Выделить все слова |
| `.` | выбор слов | Выделить следующее слово по порядку |
| `1` `2` | выбор слов | Скрыть выделенное: обычно или через вопросы |
| `Cmd`+`C` | выбор слов | Скопировать материал — то же, что кнопка |
| `1` | папка флеш-карточек | «Изучать» — открыть режим «Карточки» с первой карточки. Если курсор стоит в поле «Срок ответа», цифра печатается в поле |
| `S` (`Ы`) | флеш-карточки, режим «Карточки» | Отметить карточку сложной или снять отметку — то же, что «☆ Сложная» |
| `Пробел` или `↓` | флеш-карточки, режим «Карточки» | Перевернуть карточку — показать оборотную сторону и обратно |
| `←` `→` | флеш-карточки, режим «Карточки» | Предыдущая и следующая карточка — то же, что «Назад» и «Дальше». На последней карточке `→` завершает занятие, как кнопка «Завершить» |
| `Enter` | флеш-карточки, режим «Карточки» | Следующая карточка — как `→` |
| `R` (`К`) | флеш-карточки, режим «Карточки» | «↺ Начать заново» — к первой карточке, с подтверждением |
| `E` (`У`) | флеш-карточки, режим «Карточки» | Открыть окно правки текущей карточки — лицевая и оборотная стороны |
| `Cmd`+`Return` | окно карточки (новой или правки), «Загрузить список карточек» | Сохранить — то же, что кнопка «Сохранить» или «Добавить». Если одна сторона пустая, окно не закрывается, курсор встаёт в неё |
| `E` (`У`) | папка флеш-карточек | Поменять местами лицевую и оборотную стороны всех карточек папки; повторно — вернуть |
| `W` (`Ц`) | список материалов, папка флеш-карточек | Сменить порядок: сначала последние добавленные или сначала первые |
| `S` | список материалов | Перемешать список |
| `N` (`Н`) | список материалов, папка флеш-карточек | Войти в режим выбора материалов (или карточек) для копирования; повторно — выйти |
| `Cmd`+`C` | список материалов или папка флеш-карточек, режим выбора | Скопировать выбранные — то же, что кнопка |
| `Cmd`+`Shift` | окно материала | Сохранить и сразу перейти к выделению слов |
| `9` | везде, кроме ввода текста, открытых окон и «Собери текст по строкам» | Открыть раздел «Карточки» — папки флеш-карточек |
| `Пробел` | плеер озвучки | Играть или пауза |
| `←` `→` | плеер озвучки | Назад или вперёд на 5 секунд |
| `↑` `↓` | плеер озвучки | Предыдущий или следующий блок |
| `Enter` | плеер озвучки, разметка на слух | Поставить границу: «Начался блок N» |
| `Escape` | везде | Закрыть окно или вернуться назад; в плеере озвучки с открытым списком скоростей — сперва закрыть список |

`Shift` нажимается сам по себе: с `Cmd` или `Ctrl` это уже сочетание, и подсказка не срабатывает. Удержание тоже не считается — одно нажатие открывает одну букву. Отметить слово сложным на компьютере можно правой кнопкой мыши по нему.

## Как это устроено внутри

Один файл `index.html` (около 22 тысяч строк, 1 МБ, по сети — около 205 КБ сжатым) на чистом JavaScript: без фреймворков, сборки, библиотек и обращений в сеть. Рядом — шрифты (`fonts/`; браузер берёт только те начертания, чьи символы есть на экране) и `sw.js` для работы офлайн. Всё состояние живёт в одном объекте; любое действие меняет его и перерисовывает экран, причём в документ переносятся только отличия. Данные лежат в `localStorage` браузера, звук — в IndexedDB. Новая версия появляется на телефоне после полного закрытия приложения.

**Ограничение, о котором стоит знать.** Картинки хранятся в `localStorage` строками base64, а браузер даёт около 5 МБ на всё хранилище — несколько крупных изображений могут его переполнить. Если планируете активно добавлять картинки, это первое, что стоит перевести на IndexedDB.

Для разработчика: с чего начинать — [CLAUDE.md](CLAUDE.md), карта кода — [ARCHITECTURE.md](ARCHITECTURE.md), подробности по темам — папка [docs/](docs/).

## Экономия батареи

Приложение почти не влияет на заряд:

- **В простое не работает ничего.** Нет сети, фоновых задач, таймеров и анимаций — проверено замером на 14 экранах (2026-10-20). Свёрнутое приложение не тратит процессор: таймер останавливается, несохранённое записывается на диск, перерисовка откладывается.
- **Нажатие стоит дёшево.** Экран обновляется точечно, а не пересобирается; частые действия — открыть слово, подсказка, фокус, следующая карточка — стоят 2–5 мс и ничего не пишут на диск. На диск попадают только настоящие изменения: разметка, отметки, тексты, порядок.
- **Прокрутку ведёт браузер.** Приложение не следит за каждым движением пальца — только пока палец держат на слове для долгого нажатия.
- **Анимаций мало, и они дешёвые.** Появляются только видимые карточки и только при входе на экран; нет размытия подложки и пульсаций; системная настройка «Уменьшение движения» выключает анимации совсем.
- **Большие папки не тормозят.** Строки за краем экрана не рисуются: папка в 1000 карточек обновляется примерно за 20 мс.
- Тема следует системной настройке, пока не выбрана вручную; картинки грузятся лениво.

Все замеры и история оптимизаций — [docs/performance.md](docs/performance.md).

## Разработка

Сборки нет. Откройте приложение через локальный сервер (через `file://` service worker не регистрируется):

```bash
python3 -m http.server 8000
```

и адрес `http://localhost:8000/index.html?v=2` — меняющийся параметр обходит кэш браузера. **Меняете `index.html` — поднимите версию кэша в первой строке `sw.js`** (`zapominalka-vN` → `N+1`): service worker работает «сначала кэш», и без новой версии телефон останется на старой копии. Все правила — в [CLAUDE.md](CLAUDE.md), что проверять после правок — в [docs/workflow.md](docs/workflow.md).
