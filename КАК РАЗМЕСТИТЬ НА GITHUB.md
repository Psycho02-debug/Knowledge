# Как разместить Запоминалку на GitHub Pages

## Что это и зачем

GitHub Pages — бесплатный хостинг от GitHub. После размещения у приложения будет постоянный адрес вида `https://ВАШ_НИК.github.io/zapominalka/`. В Safari на iPhone можно добавить его на рабочий стол — и оно будет работать как обычное приложение, полностью офлайн.

---

## Шаг 1 — Создать аккаунт GitHub

Если аккаунта нет: зайти на **github.com** → Sign up → ввести email, пароль, имя пользователя.

---

## Шаг 2 — Создать репозиторий

1. Войти в GitHub → нажать кнопку **"New"** (или плюс в правом верхнем углу → "New repository")
2. Repository name: `zapominalka`
3. Убедиться что выбрано **Public**
4. Нажать **"Create repository"**

---

## Шаг 3 — Загрузить файлы

1. На странице пустого репозитория нажать **"uploading an existing file"** (ссылка в середине страницы)
2. Перетащить в окно загрузки все файлы из этой папки `pwa/`:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`
3. Нажать **"Commit changes"**

> **Папку `fonts/` загружать не нужно** — шрифты уже встроены в index.html.

---

## Шаг 4 — Включить GitHub Pages

1. В репозитории нажать **Settings** (вкладка вверху)
2. В левом меню найти **Pages**
3. В разделе "Branch" выбрать **main** → папку **/ (root)** → нажать **Save**
4. Подождать 1-2 минуты

Адрес приложения появится в том же разделе:  
`https://ВАШ_НИК.github.io/zapominalka/`

---

## Шаг 5 — Установить на iPhone

1. Открыть адрес в **Safari** на iPhone
2. Нажать кнопку **"Поделиться"** (квадрат со стрелкой вверх)
3. Выбрать **"На экран «Домой»"**
4. Нажать **"Добавить"**

Приложение появится на рабочем столе с иконкой и будет открываться в полноэкранном режиме.

---

## Как обновить приложение потом

Когда приложение изменилось и нужно залить новую версию:

### Шаг 1 — Поднять версию кэша

Открыть `sw.js` и увеличить номер версии на единицу:

```js
const CACHE = 'zapominalka-v25';  // было — номер в конце
const CACHE = 'zapominalka-v26';  // стало — увеличили на единицу
```

> **Это обязательно.** Приложение работает офлайн и берёт файлы из своей памяти. Если номер версии не изменить, телефон продолжит показывать старую версию, сколько бы раз вы ни обновляли страницу.

### Шаг 2 — Загрузить изменённые файлы

1. В репозитории нажать **Add file → Upload files**
2. Перетащить изменённые файлы — обычно это `index.html` и `sw.js`
3. Нажать **Commit changes**
4. Подождать 1–2 минуты

Файлы с одинаковыми именами перезапишут старые.

### Шаг 3 — Обновить на iPhone

1. Открыть приложение с домашнего экрана
2. **Полностью закрыть его** — свайп вверх в переключателе приложений (просто выйти на домашний экран недостаточно)
3. Открыть снова

Если изменения всё равно не появились — открыть адрес обычной вкладкой в Safari, потянуть страницу вниз для перезагрузки, затем снова запустить с домашнего экрана.

**Ваши материалы при обновлении не пострадают** — они хранятся отдельно от файлов приложения.

---

## Обновление через Git (необязательно)

Если не хочется каждый раз перетаскивать файлы вручную, в папке `pwa/` уже настроен git-репозиторий. Тогда обновление — одна команда:

```bash
git add -A && git commit -m "что изменил" && git push
```

Для этого нужно один раз подключить удалённый репозиторий:

```bash
git remote add origin git@github.com:ВАШ_НИК/zapominalka.git
git push --force -u origin main
```

`--force` нужен только при самой первой отправке, если файлы до этого загружались вручную — истории двух версий не связаны между собой. Дальше он не понадобится.

---

## Важно

- **Данные хранятся только на вашем iPhone** — никуда не уходят
- **Работает офлайн** — после первого открытия интернет не нужен
- **Приложение почти не тратит батарею** — нет сети, фоновых задач и работы в свёрнутом виде
- **Данные не удаляются** при обновлении Safari или iOS (в отличие от обычного сайта в браузере)
- Если очистить "Данные сайтов" в настройках Safari — данные удалятся. Но через иконку на рабочем столе этого не происходит автоматически.
- Картинки хранятся вместе с данными, а места браузер даёт около 5 МБ — несколько крупных фото могут его исчерпать
