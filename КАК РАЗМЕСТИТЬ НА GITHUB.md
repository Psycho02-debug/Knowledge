# Как разместить Запоминалку на GitHub Pages

## Что это и зачем

GitHub Pages — бесплатный хостинг от GitHub. После размещения у приложения будет постоянный адрес вида `https://ВАШ_НИК.github.io/zapominalka/`. В Safari на iPhone можно добавить его на рабочий стол — и оно будет работать как обычное приложение, полностью офлайн.

---

## Шаг 1 — Создать аккаунт GitHub

Если аккаунта нет: зайти на **github.com** → Sign up → ввести email, пароль, имя пользователя.

---

## Шаг 2 — Создать репозиторий

1. Войти в GitHub → нажать кнопку **"New"** (или плюс в правом верхнем углу → "New repository")
2. Repository name: `zapominalka`
3. Убедиться что выбрано **Public**
4. Нажать **"Create repository"**

---

## Шаг 3 — Загрузить файлы

1. На странице пустого репозитория нажать **"uploading an existing file"** (ссылка в середине страницы)
2. Перетащить в окно загрузки все файлы из этой папки `pwa/`:
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon-192.png`
   - `icon-512.png`
   - `apple-touch-icon.png`
3. Нажать **"Commit changes"**

> **Папку `fonts/` загружать не нужно** — шрифты уже встроены в index.html.

---

## Шаг 4 — Включить GitHub Pages

1. В репозитории нажать **Settings** (вкладка вверху)
2. В левом меню найти **Pages**
3. В разделе "Branch" выбрать **main** → папку **/ (root)** → нажать **Save**
4. Подождать 1-2 минуты

Адрес приложения появится в том же разделе:  
`https://ВАШ_НИК.github.io/zapominalka/`

---

## Шаг 5 — Установить на iPhone

1. Открыть адрес в **Safari** на iPhone
2. Нажать кнопку **"Поделиться"** (квадрат со стрелкой вверх)
3. Выбрать **"На экран «Домой»"**
4. Нажать **"Добавить"**

Приложение появится на рабочем столе с иконкой и будет открываться в полноэкранном режиме.

---

## Важно

- **Данные хранятся только на вашем iPhone** — никуда не уходят
- **Работает офлайн** — после первого открытия интернет не нужен
- **Данные не удаляются** при обновлении Safari или iOS (в отличие от обычного сайта в браузере)
- Если очистить "Данные сайтов" в настройках Safari — данные удалятся. Но через иконку на рабочем столе этого не происходит автоматически.
