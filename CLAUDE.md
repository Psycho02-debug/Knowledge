# Запоминалка слов — основной контекст

Офлайн-PWA для запоминания: тексты со скрытыми словами, флеш-карточки, мини-курсы. Русскоязычное, для одного пользователя, ставится на iPhone с домашнего экрана. Сайт — https://psycho02-debug.github.io/Knowledge/, репозиторий `Psycho02-debug/Knowledge`, ветка `main`.

Этот файл загружается в каждую сессию, поэтому здесь только то, что нужно всегда. Остальное — в документах по таблице ниже: **читайте только раздел, нужный задаче**, и не открывайте весь `index.html` — ищите по имени.

## Код в пяти фактах

1. Всё приложение — `index.html` (~21 900 строк, 1 МБ): стили ≈13–7021, разметка 14 модальных окон ≈7029–7338, скрипт ≈7341–21852. Рядом `sw.js`, `manifest.json`, иконки, `fonts.css` и `fonts/` (41 начертание — не трогать: имя файла и есть содержимое). Ни сборки, ни библиотек, ни обращений в сеть.
2. Скрипт классический, не модуль: все функции глобальные, обработчики — строки `onclick="fn()"` в шаблонах. Переименовывая функцию, ищите имя и в шаблонных строках; модуль или IIFE сломает все `onclick`.
3. Одно состояние `state` (объявлен через `let`: в `window` его нет, из `iframe` — `frame.contentWindow.eval('state')`). Действие меняет `state` и данные → `render()` → `renderScreen()` → `render*View()` собирает HTML-строку → `setAppHtml()` переносит в документ только отличия (`patchChildNodes`) или пересобирает экран.
4. Данные — в `localStorage` (`wordMemorizer` и ещё шесть ключей), звук — в IndexedDB. Запись отложенная: `saveData()` пишет в простое.
5. Язык интерфейса, комментариев, коммитов и документации — русский; английский — только имена в коде.

Поиск: `grep -n -E "^        (async )?function " index.html` — все функции со строками; `grep -n "имя" index.html` — определение и вызовы, включая `onclick`. graphify разбирает только `.md`, `sw.js` и `manifest.json` — для кода нужен `grep`. Номера строк в документах — ориентир для v159.

## Обязательное при каждой правке

1. **Изменили `index.html` — поднимите `CACHE` в первой строке `sw.js`** (`zapominalka-vN` → `N+1`). Service worker работает «сначала кэш»: без новой версии телефон покажет старую копию — это причина номер один жалоб «правка не появилась». `cache: 'no-cache'` при установке в `sw.js` не убирать (иначе в новый кэш попадает прошлый `index.html`). Правка одних `.md` версию не меняет.
2. **Проверьте в браузере**: `python3 -m http.server 8000` в `pwa/`, адрес с меняющимся `?v=N` ([docs/workflow.md](docs/workflow.md)).
3. **Обновите документацию**, по-русски:
   - поведение или клавиша для пользователя → README (раздел возможностей, таблица клавиш);
   - устройство (область кода, поле `state` или данных, экран, слушатель, файл) → ARCHITECTURE.md или docs-файл по теме из таблицы выше;
   - новая ловушка → «Правила» в docs-файле темы, а если она касается любой правки — список ниже;
   - в шапке изменённого документа — дата и версия в строке «Сверено с кодом».
4. **`graphify update .`** в `pwa/` (только разбор, без затрат).
5. **Коммит и пуш — без вопросов**: пользователь дал постоянное разрешение для этого репозитория (доступ по SSH-ключу `claude-deploy-igra`).
   - Автор — только скрытая почта `277745190+Psycho02-debug@users.noreply.github.com` (стоит в `.git/config`; в свежем клоне проверьте `git config user.email`). Репозиторий публичный, личную почту не светить. Старые коммиты с личной почтой остаются — историю без решения пользователя не переписывать.
   - Без `--force`. Сообщение по-русски — что изменилось для пользователя, в конце строка соавторства, которую задаёт среда.
   - Перед коммитом удалить временные файлы (`_baseline.html`, `_test_*`, замеры, тестовые звуки). `graphify-out/` в git не идёт (`.gitignore`).
   - Материалы пользователя живут только в `localStorage` и IndexedDB браузера и в git не попадают. Если в коммит попадает что-то кроме кода и документации (данные, ключи) — остановиться и спросить.
6. **После пуша проверьте выкладку** — она иногда срывается на стороне GitHub (v159: «Timeout reached, aborting!» на шаге Deploy, затем долгая очередь из-за сбоя Actions; сайт оставался на прошлой версии). Без `gh`:
   - `curl -s "https://api.github.com/repos/Psycho02-debug/Knowledge/actions/runs?per_page=1"` — последний `pages build and deployment` должен быть `completed` / `success`;
   - `curl -s "https://psycho02-debug.github.io/Knowledge/sw.js?nocache=$(date +%s)" | head -1` — новая версия;
   - упало — пустой коммит `git commit --allow-empty -m "Повторная публикация vN"`, пуш и проверить снова; висит в очереди — посмотреть https://www.githubstatus.com и подождать.
   - Пользователю напомнить: новая версия появляется на iPhone после полного закрытия приложения.

Честность: проверки идут во встроенном браузере Claude, на настоящем iPhone ничего не проверялось, пока пользователь не сказал обратного, — так и сообщайте.

## Правила, которые уже нарушали

По строке на правило; почему и как — по ссылке.

- **Индексы слов** — позиции в `content.split(/(\s+)/)` вместе с пробелами; любой код токенизирует ровно так. Новое поле с индексами учите переносу в `remapProcessedTextState`, `repairWordIndexAlignment`, `applyPunctuationSplitToText`. → [data.md](docs/data.md)
- **Индекс материала двух видов**: `state.currentText` — в папке, `openText(vi)` и экран «Материалы» — в видимом списке (`getTextLocationFromListIndex`). → [data.md](docs/data.md)
- **Открытые слова и буквы подсказки** (`revealedWords`, `halfRevealedWords`, `hintLetters`) — состояние экрана, на диск не пишутся. → [data.md](docs/data.md)
- **Форма материала** задаётся только в `ensureTextStudyData()`; новые поля — туда. → [workflow.md](docs/workflow.md)
- **Не навешивайте слушатели после `render()`** — инлайновый атрибут или один делегированный слушатель при старте; экран «Материалы» поэтому не патчится. → [rendering.md](docs/rendering.md)
- **Рядом с полями ввода условные блоки не вставлять и не убирать** — рисовать всегда и прятать классом, иначе на iPhone закрывается клавиатура. → [rendering.md](docs/rendering.md)
- **Обработчик чипа слова зависит от состояния — меняйте и класс чипа**: патч не сверяет `onclick`. → [rendering.md](docs/rendering.md)
- **`render…View` не меняют `hiddenWords` и `hiddenWordGroups`** (память `renderGroupsMemo`). → [rendering.md](docs/rendering.md)
- **Новый `transition` оживает при патче** — проверьте, не играет ли он на каждое действие. → [rendering.md](docs/rendering.md)
- **Текст практики не скачет**: кнопки дока гасить `disabled`, а не прятать; плашка 1.7em при шаге строки не меньше 2.0em; центрирование текста на каждой отрисовке не возвращать; прокрутка к слову — только вниз. → [rendering.md](docs/rendering.md)
- **Пользовательский текст — через `escapeHtml()`, в атрибуты — `escapeHtmlAttr()`.** → [rendering.md](docs/rendering.md)
- **Каскад появления — только первые 16 элементов и около секунды**: дольше — iPhone теряет нажатия. → [rendering.md](docs/rendering.md)
- **`focus()` поля, `play()` звука, `input.click()` — синхронно внутри жеста**, иначе iOS их не выполнит. → [input.md](docs/input.md), [audio.md](docs/audio.md)
- **Новая клавиша — по порядку проверок диспетчера и в обеих раскладках.** → [input.md](docs/input.md)
- **«Строка по кругу» берёт скрытые слова только из `getRenderableHiddenIndices` и `computePracticeFocusTargets`**; скрывают слова только в «Выборе», своих отметок у режима нет. → [practice.md](docs/practice.md)
- **Число — не обязательно номер пункта**: где важна позиция — `isLineStartListMarker`, скрытое слово фокус не пропускает никогда. → [practice.md](docs/practice.md)
- **Ничего тяжёлого в `localStorage`**: звук — IndexedDB через `saveAudioClip`; удаляя материал, модуль или папку — `forgetTextAudio` / `forgetFolderAudio`. Автоматической озвучки нет (убрана в v138) — возвращать только по просьбе. → [audio.md](docs/audio.md)
- **Батарея**: ни `setInterval`, ни бесконечных анимаций, ни `backdrop-filter`, ни `filter` на массовых элементах, ни анимаций `width`/`height`/`top`; `touchmove`, `scroll`, `pointermove` — только на время жеста; в простое — ни одного таймера. → [performance.md](docs/performance.md)
- **Оптимизация обязана давать тот же результат** — сравнение с прошлой версией (`_baseline.html`). → [performance.md](docs/performance.md)
- **Селекторы стилей повторяются (19 штук)** — правя стиль, найдите все вхождения. → [ARCHITECTURE.md](ARCHITECTURE.md), §3
- **Панель режимов скопирована девять раз** — режим добавлять и переименовывать во всех копиях. → [ARCHITECTURE.md](ARCHITECTURE.md), §4
- **Переносимый текст приходит испорченным** — разбор строить на `normalizeImportLineBreaks` и `parseImportTitleLine`. → [transfer.md](docs/transfer.md)
- **Комментарии в коде местами устарели** — сверяйтесь с кодом и правьте устаревший комментарий в месте правки. → [workflow.md](docs/workflow.md)
