# Ввод: слушатели, клавиатура, окна

> **Когда читать:** новая или изменённая клавиша, слушатель события, модальное окно, работа с фокусом поля ввода.  
> **Сверено с кодом:** 2026-11-04, версия кэша `zapominalka-v159`. Номера строк — ориентир для v159, ищите по имени функции.  
> **Связано:** [practice.md](practice.md), [modes.md](modes.md), [audio.md](audio.md) — клавиши плеера, README — таблица клавиш для пользователя · наверх: [CLAUDE.md](../CLAUDE.md), [ARCHITECTURE.md](../ARCHITECTURE.md)

## Как обработчики попадают на элементы

1. **Строкой в разметке**: `onclick`, `oninput`, `onkeydown`, `onpaste`, `onmousedown` — основной способ, тысячи мест. Вызывают глобальные функции.
2. **Глобальные слушатели**, навешенные один раз при загрузке скрипта:

| Строка (≈ v159) | Событие | Зачем |
|---|---|---|
| 9134 | `document` `visibilitychange` | Сворачивание: остановить таймер карточек и сбросить запись. Возврат: выполнить отложенную отрисовку |
| 9152–9153 | `window` `pagehide`, `beforeunload` | `flushPendingPersistence` |
| 9159 | `window` `resize` | `syncDockSpacing` не чаще раза за кадр |
| 10482 | `visualViewport` `resize` | В «Вписать» — подстроить высоту текста под экранную клавиатуру |
| ≈13895 | `document` `touchstart`, `touchend`, `touchcancel`, `mousedown`, `mouseup`, `mouseleave` | Долгое нажатие (480 мс) — отметить слово сложным. `touchmove` подключается **только на время отсчёта** (`startHardPress` → `cancelHardPress`), чтобы обычная прокрутка не вызывала JavaScript |

Дорожка плеера (`#apTrack`) получает `pointermove`, `pointerup`, `pointercancel` только на время жеста — их вешает `onAudioTrackPointerDown` и снимает `endAudioTrackDrag`. Так же и список скоростей: `pointerdown` на документе (в фазе перехвата, `onAudioRateMenuOutside` — закрыть список при нажатии мимо) висит, только пока список открыт; вешает и снимает его `setAudioRateMenu`, а закрывают список выбор скорости, нажатие мимо, `Escape` и закрытие плеера.

3. **После каждой отрисовки экрана «Материалы»** — `initTermCardSwipe()` (свайп вправо — сложный, влево — снять пометку; `touchmove` пассивный, ось жеста задаёт `touch-action: pan-y` у `.term-card`) и `initDragReorder()` (перетаскивание за ручку). Это единственное исключение из правила «не навешивать слушатели после render» — и причина, по которой этот экран не патчится ([rendering.md](rendering.md), «Правила»).

## Диспетчер клавиатуры (≈21357): порядок проверок

Первое сработавшее правило завершает обработку. Новую клавишу вставляйте с учётом этого порядка.

1. Открыто окно вопросов (`batchHintModal`) — `,` `.` `б` `ю` игнорируются.
2. `Escape` → `handleEscapeAction()`: закрыть окно или вернуться назад. Затем `Cmd/Ctrl+Enter` при открытом `flashcardModal` → `saveFlashcard()`, при `flashcardImportModal` → `applyFlashcardImport()` (если кнопка «Добавить» активна). Стоит до шага 5 — нажимают из полей окна. Окно материала сохраняет по `Cmd+Enter` своим `handleTextModalKeys` на полях.
3. «Вписать» завершено, `Enter` пришёл не из поля → следующий материал.
4. Из поля `#typeInputField`: `↓` → фокус на строке; `←` `→` без модификаторов → соседний материал.
5. Фокус в любом другом `INPUT` или `TEXTAREA` → **дальше не идём**. Сразу за этим, без Cmd/Ctrl/Alt — открытый плеер озвучки (`handleAudioPlayerKey`): `Пробел` — играть/пауза (с `preventDefault`, иначе пробел нажал бы и кнопку в фокусе), `←` `→` — на 5 секунд, `↑` `↓` — блоки, `Enter` при разметке на слух — граница. Стоит раньше шага 19, иначе стрелки листали бы материалы под окном.
6. `Cmd/Ctrl+C` → «Скопировать материал» (выбор слов) или «Скопировать выбранные» (список материалов или папка флеш-карточек в режиме выбора). Во встроенном браузере Claude настоящее `Cmd+C` до страницы не доходит — проверять программным событием.
7. `Ctrl` без `Cmd` → выход. Затем «Собери текст по строкам» (`mode === 'game'`, `gameState.byLines`): цифра `0`–`9` дальше не идёт — с Cmd или Alt просто выход (сочетание браузера), иначе `preventDefault` и, если не автоповтор и нет окна, `selectGameTileByKey` (`1`…`9` — плитки 0…8, `0` — плитка 9; собранная плитка, `lineDone` и `completed` — ничего). Стоит до `9` и смены режимов (шаг 9), иначе цифра выкидывала бы из игры. Затем `9` на любом экране (без открытых окон и `contenteditable`) — `openLearningBranch('cards')`, раздел «Карточки»; эта функция заодно выключает полноэкранную «Карточку».
8. Выбор слов: `1` — скрыть выделенное, `2` — скрыть через вопросы (только если что-то выделено; иначе `1`–`4` здесь молчат). `5` — «Вписать», `6` — «Строка по кругу» (`7` здесь не работает: она не входит в эту проверку).
9. `1`–`7` на экране материала, в «Вписать» и в практике → `switchStudyModeByHotkey` (`5` — «Вписать», `6` и `7` — «Строка по кругу»; раньше обе открывали убранный «По строкам»).
10. Выбор слов: `/` — выделить все, `.` — следующее слово.
11. Список материалов: `N` — режим выбора, `W` — сортировка, `S` — перемешать. Папка флеш-карточек: `N` — режим выбора карточек, `W` — порядок списка (только если есть карточки и нет окон).
12. Внутри материала: `E` — правка. Папка флеш-карточек (`card_folder`, есть карточки, окон нет): `E`/`У` — `swapFlashcardSides`, без автоповтора (`e.repeat` игнорируется, иначе удержание меняло бы стороны туда-обратно).
13. `]` или `` ` `` — создать (на списках) или править (внутри материала).
14. Тест (материала или папки): `↑` `↓` `Enter`.
15. «Вписать»: `↓` — фокус на строке. «Собери текст по строкам», строка собрана (`gameState.lineDone`), окон нет: `Enter` — `nextGameLine()`.
16. Практика. Первым — «Строка по кругу» (`isPracticeCircleMode`, окон нет, без модификаторов): `Пробел` и `Enter` без Shift → `practiceCircleStep()`; `ж`/`Ж`/`;`/`:` → `toggleCirclePicking()` («Выделить слова» / «Готово»), `э`/`Э`/`'`/`"` → `clearCirclePicks()` («Убрать выделение»); `preventDefault` и на автоповторе, действие — только на отдельное нажатие. Когда кнопка неактивна, клавиша тоже молчит: `toggleCirclePicking` не начинает выбор на строке без скрытых слов, `clearCirclePicks` ничего не делает, если на строке ничего не выделено. Дальше для всех вариантов: `Delete`/`Backspace` — выключить фокус, `↓` — фокус дальше, `Shift` — ещё букву, `↑` — открыть или скрыть все, `Enter` — `revealNextHiddenWordInOrder()` (без фокуса — первое по тексту неоткрытое скрытое слово из `getUnrevealedFocusTargets`; с фокусом — все неоткрытые скрытые до конца связки под фокусом через `markHiddenWordsRevealed` одной отрисовкой, затем `advancePracticeFocus`, если под фокусом было скрытое слово; если до фокуса нечего — следующее после фокуса, и фокус за него; группа в «?» — один шаг; `preventDefault` и на автоповторе, иначе браузер нажал бы кнопку под фокусом), `M` — сложное слово.
17. Экран папки флеш-карточек (`card_folder`): `1` — `startFlashcardStudy(false)`, как кнопка «Изучать»; в пустой папке молчит, как неактивная кнопка.
18. Флеш-карточки, режим `flashcards`, занятие не завершено, окон нет: `S` — `toggleCurrentFlashcardAttention`, `R`/`К` — `restartFlashcardFromStart`, `E`/`У` — `showEditFlashcardModal(order[current])`, `Пробел` и `↓` — `flipFlashcard`, `→` и `Enter` — `stepFlashcard(1)`, `←` — `stepFlashcard(-1)`. `preventDefault` обязателен: после клика фокус стоит на карточке-кнопке, и браузер сам «нажал» бы её, — действие сработало бы дважды. После завершения клавиши молчат, иначе лишнее «Дальше» записало бы занятие в статистику повторно.
19. Нужен открытый материал: `←` `→` — соседний (на экране выбора — `navigateChooser`, в «Строке по кругу» — `stepPracticeLine(±1)`, он же прячет открытые слова строки, с которой уходят), `R` — `resetReveal`, скрыть всё снова (практика; в «Строке по кругу» — новый круг строки), `S` — сложный материал. `Пробел` здесь ничего не делает (поштучного раскрытия пробелом в обычной практике нет); в «Строке по кругу» его раньше забирает шаг 16.

Буквы сверяются по `e.key` сразу в обеих раскладках: `e`/`у`, `m`/`м`/`ь`, `n`/`н`/`т`. `Cmd+C` — по `e.code`.

## Модальные окна (14)

Открытое окно — `.modal.show`, закрывает `closeModal(id)`. Окна статичны, лежат в `<body>` вне `#app` и при `render()` не пересоздаются:

`folderModal` (папка, модуль, папка карточек, курс — одно окно на всех), `questionModal`, `learningCreateModal`, `textModal`, `bulkImportModal`, `flashcardModal`, `flashcardImportModal`, `courseLessonModal`, `courseTaskModal`, `gameSetupModal`, `transferTermsModal`, `audioPlayerModal`, `hintModal`, `batchHintModal`. У `audioPlayerModal` статична только оболочка — всё содержимое рисует `renderAudioPlayer()`.

Окно открывает функция вида `showXxxModal()`: она заполняет поля и ставит фокус через `setTimeout(…, 100)`. Сохраняет `saveXxx()`: читает поля, меняет данные, затем `saveData()`, `closeModal()` и `render()`. `closeModal` снимает фокус с поля внутри закрытого окна: иначе фокус оставался бы в скрытом `TEXTAREA`, диспетчер считал бы, что идёт ввод (шаг 5), и горячие клавиши экрана молчали бы до клика.

## Правила

### Фокус в поле — только синхронно, внутри жеста

На iOS клавиатура поднимается, только если `focus()` вызван прямо из обработчика касания. Вызов из `setTimeout` — уже отдельная задача: поле получает фокус, а клавиатура не появляется. Поэтому `focusTypeField` ставит фокус сразу, если поле уже в документе, а кнопка «Проверить» гасит `mousedown` (`event.preventDefault()`), чтобы не забирать фокус у поля.

### Постоянных слушателей прокрутки и движения пальца нет

`touchmove` на документе подключается только на время отсчёта долгого нажатия на слово и снимается вместе с таймером. Постоянный слушатель вызывался бы при каждой прокрутке десятки раз в секунду. Новые обработчики `touchmove`, `scroll`, `pointermove` вешайте так же — только на время жеста.
